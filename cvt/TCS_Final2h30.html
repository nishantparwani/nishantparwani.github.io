★ Reference — Definitions · Tuples · Points · Cheat Sheet

Definitions

DFA
M=(Q,Σ,δ,q0,F) · δ:Q×Σ→Q (total) · accepts if δ*(q0,w)∈F
NFA
M=(Q,Σ,δ,q0,F) · δ:Q×(Σ∪{ε})→2^Q · accepts if δ*(q0,w)∩F≠∅
Mealy Machine
M=(Q,Σ,Δ,δ,λ,q0) · λ:Q×Σ→Δ · output on transitions
Moore Machine
M=(Q,Σ,Δ,δ,λ,q0) · λ:Q→Δ · output on states · |out|=|in|+1
CFG
G=(N,T,P,S) · A→γ where A∈N, γ∈(N∪T)* · Type-2
CNF
Every prod: A→BC or A→a · (S→ε if ε∈L)
GNF
Every prod: A→aα · a∈T (terminal first), α∈N*
PDA
M=(Q,Σ,Γ,δ,q0,Z0,F) · δ:Q×(Σ∪{ε})×Γ→subsets of Q×Γ*
TM
M=(Q,Σ,Γ,δ,q0,B,F) · δ:Q×Γ→Q×Γ×{L,R} · infinite tape
Recursive Language
TM always halts (accepts or rejects). = Decidable.
RE Language
TM accepts all w∈L, may loop on w∉L. = Recognizable.
Ambiguous Grammar
∃ string w with 2+ distinct parse trees (or 2 LMDs).
UTM
TM U that simulates any TM M on input w. Takes ⟨M,w⟩ as input.
Halting Problem
HALT={⟨M,w⟩|M halts on w} — UNDECIDABLE (Turing 1936).
Church-Turing Thesis
Any effectively computable function = TM computable. Thesis, not theorem.
Arden's Theorem
X = XP + Q, ε∉P → unique solution X = QP*

All Formal Tuples & Key Transitions

DFA = (Q, Σ, δ, q0, F)
δ : Q × Σ → Q
Complement: swap F ↔ Q\F
Product (∩): states = Q1×Q2, final = F1×F2
NFA = (Q, Σ, δ, q0, F)
δ : Q × (Σ∪{ε}) → 2^Q
ε-closure(q) = all states via ε from q
DFA state = subset of NFA states
Mealy = (Q, Σ, Δ, δ, λ, q0)
δ : Q × Σ → Q
λ : Q × Σ → Δ (output on edge)
→Moore: transition output = dest state output
Moore = (Q, Σ, Δ, δ, λ, q0)
δ : Q × Σ → Q
λ : Q → Δ (output on state)
→Mealy: split states by incoming output
PDA = (Q, Σ, Γ, δ, q0, Z0, F)
δ : Q × (Σ∪{ε}) × Γ → fin.subsets(Q×Γ*)
Notation: δ(q,a,A) = {(p,γ)}
means: read a, pop A, push γ, go to p
Accept: final state OR empty stack
TM = (Q, Σ, Γ, δ, q0, B, F)
δ : Q × Γ → Q × Γ × {L,R}
δ(q, X) = (p, Y, R) means:
in state q, reading X → write Y, move R, go to p
B = blank ∈ Γ\Σ
Pumping Lemma (Regular)
∃p: ∀w∈L,|w|≥p: w=xyz
(1)|xy|≤p (2)|y|≥1 (3)∀i≥0: xyⁱz∈L
Pumping Lemma (CFL)
∃p: ∀w∈L,|w|≥p: w=uvxyz
(1)|vxy|≤p (2)|vy|≥1 (3)∀i≥0: uvⁱxyⁱz∈L

Points to Remember

Complement DFA = same diagram, swap final ↔ non-final. No new states.
Product DFA for two conditions: states = n₁×n₂. Final = both conditions met.
NFA→DFA worst case: 2^n DFA states. Usually far fewer reach.
Arden's: write equation per state (start gets ε). Apply X=QP* when X appears on both sides.
Minimization: (1) remove unreachable, (2) table-fill distinguishable pairs, (3) merge equivalent.
Regular closed under: ∪, ∩, complement, concat, *, reversal, homomorphism.
CFL closed under: ∪, concat, *. NOT ∩, NOT complement. CFL∩Regular=CFL ✓
Pumping Lemma: to DISPROVE regularity only. y always lands in first symbol block.
Moore→Mealy: output of transition = destination state's Moore output. Same state count.
Mealy→Moore: split states with different incoming output labels. More states in Moore.
Moore for binary mod-3: δ(qi,b) = (2i+b) mod 3. 3 states: q0(out 0), q1(out 1), q2(out 1).
CFG simplification order: (1) remove ε-prods, (2) unit prods, (3) useless symbols.
CNF: 4 steps — remove ε → remove unit → terminal in long rules → binary-ify.
GNF: substitute to remove leading non-terminals → remove left recursion (A→Aα|β becomes A→βA', A'→αA'|ε).
Ambiguity: ONE string, TWO parse trees = ambiguous grammar.
Unambiguous expression grammar: E→E+T|T; T→T*F|F; F→(E)|a (precedence encoded).
PDA for aⁿbⁿ: push A for a's, pop A for b's. Accept when stack has only Z₀.
PDA for palindrome: push first half, ε-move to guess midpoint, pop matching second half.
TM cross-off: mark 1 of each required symbol per iteration, return left, repeat.
TM palindrome/w#w: remember leftmost symbol in state, find rightmost, compare, cross off both.
Recursive = TM always halts (decider). RE = TM may loop on "no" (recognizer).
Halting: assume decider H, build D = invert H on itself → D(⟨D⟩) = paradox → H can't exist.
1 stack=PDA=CFL. 2 stacks=TM. aⁿbⁿ:CFL. aⁿbⁿcⁿ:NOT CFL, needs TM.
Type-3 grammar: A→aB or A→a (right-linear). A→Ba or A→a (left-linear). Mixed = CFG.

Cheat Sheet

Chomsky Hierarchy

  • Type-3: A→aB | a → Regular → DFA/NFA
  • Type-2: A→γ → CFL → PDA
  • Type-1: αAβ→αγβ → CSL → LBA
  • Type-0: any → RE → TM
  • Hierarchy: Reg ⊂ CFL ⊂ Rec ⊂ RE ⊂ ALL

NFA → DFA Template

  • Start state: ε-closure({q0})
  • δ_DFA(S, a) = ε-closure(∪{δ(q,a)|q∈S})
  • DFA final = any subset containing NFA final
  • Dead state = ∅ (non-final, self-loops)
  • Continue until no new states

CNF — 4 Steps

  • 1. Find nullable vars → add all 2^k combos without them
  • 2. Expand unit prods (A→B → A→all B's prods)
  • 3. Replace terminal in long rule: Ca→a
  • 4. Break long rules: A→BCD → A→BX; X→CD

GNF — Key Steps

  • 1. Number vars; ensure Ai→Ajα only if j>i
  • 2. Left recursion removal: A→Aα|β → A→βA'; A'→αA'|ε
  • 3. Substitute back so all prods start with terminal
  • Result: every prod = A → aX₁X₂...

PDA Design Patterns

  • aⁿbⁿ: push A per a, pop A per b
  • equal a's b's: push A for a (cancel B), push B for b (cancel A)
  • Palindrome: push 1st half, ε-move, pop 2nd half
  • aⁿb³ⁿ: push 1 A per a, pop 3 A's per b
  • m+k=n: push A per a, pop A per b (excess→push B), pop B per c

TM Design Patterns

  • aⁿbⁿcⁿ: mark 1a, 1b, 1c per round
  • wwᴿ / w#w: leftmost↔rightmost compare, cross off
  • 0ⁿ1²ⁿ: 1 zero → 2 ones per round
  • ×2 binary: append 0 at right end
  • Increment unary: find first B, write symbol

Pumping Lemma Template

  • 1. Assume L regular, let p = pumping length
  • 2. Choose w∈L with |w|≥p (use p as exponent)
  • 3. For ANY xyz split (|xy|≤p, |y|≥1):
  • 4. Show ∃i: xyⁱz ∉ L → Contradiction → not regular
  • y always falls in first symbol block

Decidability Quick Facts

  • Regular: ALL classic problems decidable ✓
  • CFL: membership ✓ · equivalence ✗ · ambiguity ✗
  • Recursive: membership decidable ✓
  • RE: membership semi-decidable (may loop)
  • Halting: UNDECIDABLE ✗
  • 1 stack=PDA · 2 stacks=TM (same power as TM)
